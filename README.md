## 🚀 Proyectos destacados

### 🚐 Página Web y Sistema de Información – Cooperativa Transportes Tierradentro
Proyecto de grado de Ingeniería de Sistemas, **en producción** en [tierradentrotransportes.com](https://tierradentrotransportes.com). Digitalizó los procesos que la cooperativa (Inzá, Cauca) llevaba en papel.
- **Página web institucional:** historia en línea de tiempo, servicios con carruseles de vehículos, rutas y tarifas oficiales, contacto y WhatsApp
- **Sistema de gestión con roles** (Administrador / Socio): socios, documentos, finanzas, vehículos, reportes y notificaciones
- Control automático de vencimientos (SOAT, Tecnomecánica, pólizas) y **paz y salvo en PDF**
- Recuperación de contraseña con código por correo (**PHPMailer + SMTP**), contraseñas con hash y diseño responsivo
- Levantamiento de requisitos, gestión de cambios como gerente del proyecto y manual de usuario

### 🚚 Data Warehouse – Transportes_dw
Data Warehouse con **esquema estrella** (6 dimensiones + `fact_viajes` con 50.000 registros) para analizar ingresos, costos, rentabilidad, rutas y desempeño de conductores.
- Pipelines **ETL** (Python + Pandas) y **ELT** (MySQL staging + SQL) con resultados equivalentes
- Orquestación diaria con **Dagster** (validación → staging → transformación)
- Réplica del modelo en **Google BigQuery** y dashboard analítico en Python

### 🎯 Segmentación Avanzada de Clientes
Sistema de segmentación sobre el *Online Retail Dataset* (UCI) para estrategias de marketing personalizadas.
- Ingeniería de variables **RFM** (Recency, Frequency, Monetary)
- Clustering (**K-Means / DBSCAN / GMM**) + **PCA / t-SNE** + **Autoencoders**
- Validación con Silhouette, Davies-Bouldin y Calinski-Harabasz
- **Dashboard interactivo** con filtros por segmento, país y gasto, KPIs y perfiles (VIP, Leales, En riesgo, Nuevos)

### 🎓 Análisis de Admisión Universitaria
Análisis descriptivo de datos de admisión con informe técnico y sustentación ejecutiva para la junta administrativa.
